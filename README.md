# 🌐 Lingua Flow — Neural Multilingual Text Translator

A clean, responsive multilingual translator powered by Groq's fast `llama-3.3-70b-versatile` language model.

## Features
- **14+ Supported Languages**: English, Spanish, French, German, Hindi, Japanese, Chinese, Arabic, Portuguese, Korean, Italian, Russian, Turkish, and Auto-Detect.
- **Bidirectional Quick-Swap**: Swap source and target languages instantly with one click.
- **Context-Preserving Translations**: Handles idiomatic nuances, cultural phrasing, and technical terminology.
- **Real-Time Character Count**: Live text counter for tracking input length.
- **One-Click Copy**: Copy translations directly to the clipboard.

## Getting Started
1. Open `index.html` in your web browser.
2. Click **Settings (⚙️)** and enter your Groq API Key.
3. Select your source and target languages.
4. Type or paste your text and click **Translate**!


## ⌨️ Keyboard Shortcuts
- `Esc`: Close settings and overlay dialogs
